# cadutome.com.br

Landing page pessoal de Carlos Eduardo Tomé da Silva: projetos, números e trajetória.

Feita com React, TypeScript, Vite, Tailwind CSS e Motion. Publicada no GitHub Pages a cada push na `main`.

## Rodar localmente

```bash
npm install
npm run dev
```

Todo o conteúdo da página fica em [`src/data/profile.ts`](src/data/profile.ts).
